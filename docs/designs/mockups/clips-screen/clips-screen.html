Clips screen rework (follow-up to #144)

Debug-only founder tool (T47). Today it's one row per picture (title, 3 order chips, 3 format chips, Render) for every bundled and remote picture: a long scroll. The founder asked for a picture dropdown and several languages in one render, picked by chips, without switching the app's language. Built from the existing parts: Chip (lamp outline = on), QuietButton, felt surfaces, Figtree. 360dp phone.

A · One panel with a picture dropdown

One panel in place of the list. The dropdown shows the picked picture (thumbnail, title, size). Languages are checkbox chips in their own names, the app's language on by default; "All" turns every one on (or off). Render says how many languages. Files get a language suffix (wave-by-color-de.mp4, wave-before-after-de.png), so nothing overwrites; finished.png has no words and is made once.

B · The same panel plus a queue

Render becomes "Add to queue": line up several pictures, each with its own order, formats and languages, and let them all render one after another. More to build; useful for a batch of ads in one sitting.
